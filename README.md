# online-banking-database-system
SQL Server relational database project for an online banking system, including 3NF design, stored procedures, triggers, business rules, security, and concurrency control.

This project presents the design and implementation of a relational database system for an online banking platform using SQL Server and T-SQL.

## Key Features
- 3NF relational database design
- Customer, account, transaction, overdue fee, and repayment management
- Stored procedures, views, triggers, and user-defined functions
- Banking business rules for loan eligibility, overdue fee tracking, and account closure
- Database security using roles and permissions
- Concurrency control using transaction isolation and row-locking techniques

## Tools
- SQL Server
- T-SQL
- SQL Server Management Studio

## Notes
This repository contains selected SQL scripts for demonstration purposes.
